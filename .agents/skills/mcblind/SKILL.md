# 麦门盲测

本 Skill 随 McBlind 源码一起使用。从仓库根目录运行脚本，需要 Node.js 22+，无第三方依赖。

## 主持一局

运行 `node scripts/challenge.mjs` 获取北京时间今日挑战；指定同一挑战用 `node scripts/challenge.mjs <挑战码>`。输出是 JSON，包含题库来源、版本、7 道问题和答案。

- 开始时简短告知题库是官方快照还是虚构演示；演示题不得说成真实餐品营养知识。
- 一次只展示一道问题、两边餐品名称与规格；暂时隐藏数值和 `answer`。用户选 A/B 或左/右后，再按脚本答案判分，公布双方数值与单位，然后出下一题。
- 以题库的一份餐品比较，不自行换算成每 100 克；`energyKcal` 是 kcal，`protein` 是 g，`sodium` 是 mg。
- 7 题结束汇总命中数，解释答错的对比，不虚构击败率、用户排名或营养优劣结论。用户想保存或分享时，运行 `npm run dev` 并提供网页地址，让其在网页完成后导出成绩卡。
- 这是一款知识小游戏，不给出个人饮食处方；用户要点餐时回到其原本请求，本 Skill 不创建订单。

## 同步真实题库

用户要更新数据时，运行 `npm run sync`。它仅连接 `https://mcp.mcd.cn`，完成 MCP 握手与工具发现后，调用 `list-nutrition-foods`（无参数）。Token 从环境变量 `MCD_MCP_TOKEN` 或仓库根目录的 `.env.local` 读取。缺少 Token 时引导用户在 https://open.mcd.cn/mcp 登录激活，并在本机配置；不要让用户把 Token 发到聊天里，不读取剪贴板。

脚本校验和归一化后原子更新 `web/data/nutrition.json`。它只保留餐品名称与三个必要营养数值，不导出完整 MCP 响应；本地调用收据写入已忽略的 `private/`。解析、鉴权或网络失败时保留旧题库，说明实际失败原因；不要用模型记忆填空或把失败当作真实接入成功。
