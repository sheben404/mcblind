# 发布文案草稿

## 社交平台短版

你的吃麦直觉，可能没你想的那么准。

做了个 McBlind「麦门盲测」：两份餐品摆面前，猜热量、蛋白质和钠，7 道题看你能对几道。选完才亮数值，答完能出成绩卡，还能把同一套题甩给朋友。

不用注册，不用配 API Key，不用花模型调用费。用了麦当劳官方 MCP 的营养数据，把查表做成了个小游戏。

试玩：https://sheben404.github.io/mcblind/
源码：https://github.com/sheben404/mcblind

如果猜错了一题，欢迎 Star 一下，传给下一位自信的朋友。

> 已上线，内置158款官方餐品数据。可直接分享试玩链接；个人成绩请使用自己真实完成的结果。

## 面向开发者

1024 做了个小东西：McBlind / 麦门盲测。

官方 MCP 取营养数据 → 7 道二选一 → 揭晓反直觉答案 → 导出成绩海报 → 同题挑战朋友。

原生 JS + Node 标准库，零依赖，静态部署。MCP Token 只在维护者本机，玩家打开就能玩。附 Agent Skill，可以让助手来当主持人。
